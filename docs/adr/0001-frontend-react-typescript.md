# Frontend in React with TypeScript

Checkout needs a UI framework. The UI will be React with TypeScript.

React and Vue perform at the same level, so the choice rests on the ecosystem. React's community is larger and more active: more ready-made libraries, and therefore more room for the product to change. A larger, more active community is also the signal that the tool keeps evolving and growing, rather than stalling and becoming legacy technology.

The comparison used each framework's official repository, the Developer Survey, and the Octoverse:

- Stars and forks on the repository where each framework is developed today, read from the GitHub API on 17 October 2026: [facebook/react](https://github.com/facebook/react) has 251,219 stars and 51,514 forks; [vuejs/core](https://github.com/vuejs/core) has 54,657 stars and 9,259 forks.
- [Stack Overflow Developer Survey 2025](https://survey.stackoverflow.co/2025/technology): 44.7% of respondents did extensive development with React in the past year, and 17.6% with Vue.js.
- [GitHub Octoverse 2025](https://github.blog/news-insights/octoverse/octoverse-a-new-developer-joins-github-every-second-as-ai-leads-typescript-to-1/): in August 2025, TypeScript became the most used language on GitHub. That supports writing this frontend in TypeScript.

## Considered options

- **React with TypeScript.** Accepted, for the reasons above.
- **Vue.** Rejected. Performance is similar; the smaller community means fewer libraries and a weaker signal that the ecosystem will keep growing.
